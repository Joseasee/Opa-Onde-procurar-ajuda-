# 🧠 Saúde Mental Gratuita — Rio de Janeiro

Mapa interativo para encontrar serviços de saúde mental gratuitos ou de valor social no Rio de Janeiro: CAPS, clínicas-escola de psicologia, plantões psicológicos, psicanálise social, hospitais e serviços de apoio.

O ponto de partida do mapa é a **Estácio de Sá — Av. Presidente Vargas, 642 (Centro)**. Toque em outro ponto do mapa ou busque um endereço para ver as unidades mais próximas.

## Funcionalidades

- Mapa ao vivo (OpenStreetMap) com raio de busca ajustável.
- Modo offline: se não houver internet, usa uma imagem embutida do Centro.
- Filtros por tipo de atendimento, idade atendida, formato (presencial, online ou híbrido) e pagamento.
- Lista completa das unidades, ordenada pela distância, com telefone, rota e botão "Ver no mapa".
- Busca por endereço, bairro ou CEP.

## Como usar

Não precisa instalar nada. Abra o `index.html` no navegador (o `app.js` deve ficar na mesma pasta) ou publique os dois arquivos no GitHub Pages.

```
index.html   → estrutura e estilos
app.js       → lógica, dados das unidades e filtros
LICENSE      → licença MIT
```

## Aviso importante

Este projeto tem fins **informativos**. Horários, telefones e condições de atendimento podem mudar, então confirme por telefone antes de ir.

Em crise emocional, ligue para o **CVV — 188** (24h, gratuito) ou procure a UPA/CER mais próxima.
